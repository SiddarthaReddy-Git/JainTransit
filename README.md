# JainTransit

**Jain Transit** is a web application designed to help university students and staff track campus transportation facilities easily, enabling smarter journeys and faster departures.


## Features
**Departure Dashboard:** Displays organized, easy-to-read schedules for university buses.
**Route Tracking:** Helps students quickly check transit timelines to reduce wait times.
**Responsive Design:** Optimized for seamless viewing on mobile phones, tablets, and desktop computers.
